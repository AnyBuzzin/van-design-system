# Roadmap and stage gates

- **G0 — Proven baseline:** archive exact V4 source + manifest; hash and record measured Fusion results.
- **G1 — CAD-independent core:** typed spec, units, stable component IDs, dependency expressions, tolerances, test suite.
- **G2 — Fusion adapter:** sketches, bodies, explicit cut participants, parameter editing and BRep validation.
- **G3 — Change management:** controlled regeneration, identity retention, override preservation and migration rules.
- **G4 — Furniture library:** at least three varied cabinets from one joinery engine, then beds/worktops/partitions.
- **G5 — Vehicle and fitment:** measured vehicle envelopes, datums, mounting, tolerance zones, collision and access checks.
- **G6 — Manufacturing and AI:** cut lists, nesting, CAM boundary, structured AI planning and human sign-off.

**Gate to merge G2:** Tests A–D run in Fusion, after save/reopen; inspected solid shapes and zero unintended interference; logs retained.
