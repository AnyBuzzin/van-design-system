# G3 fixture specs (schema 0.2)

Fully resolved fixtures for the three data-only profiles `base@1`, `tall@1`, `overhead@1`.
Copy ONE of them to `cabinet_spec.json` beside `VanCabinetJoineryV5.py` before the first run in a
**new, empty** design. The file selects the variant on first build only; later runs in the same
design read the spec stored inside the design and never look at this file.

These sizes are test fixtures demonstrating code reuse. They are not engineering sign-off and are
not derived from any van measurement, load case or fixing design.
